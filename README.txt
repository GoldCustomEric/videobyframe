1. Создайте репозиторий на github.com (New repository).
2. Загрузите в него ВСЕ файлы из этого архива (включая папку .github).
3. Откройте вкладку Actions -> Build APK -> дождитесь зелёной галочки (~3-5 мин).
4. Внутри запуска скачайте артефакт FrameGrab-apk (в нём app-debug.apk).
5. Скопируйте APK на телефон и установите (разрешите установку из неизвестных источников).
